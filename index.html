Ghostab

A tiny experimental browser built around Ghost Engine, a small browser-engine experiment written in Rust. No Blink. No Gecko. Just a ghost.

Rust No data collected No Blink / Gecko Linux Open-source
Download Source Code

Features

Private by design

Never collects any data. No tracking, no telemetry, no accounts — your browsing stays yours.

No Blink, no Gecko

Does not use Blink or Gecko as a base. Rendering is handled by Ghost Engine, our own small engine.

Isolated clipboard

The clipboard is kept isolated so websites can't silently read or abuse what you copy.

Old-styled UI

A simple, old-styled interface. No webview cruft — just a browser that looks like a browser.

Download

Windows

Download the .exe package from GitHub releases

Run the exe. If you see a warning click View More and Run Anyway and Ghostab will open.

Download for Windows

Linux (Debian)

Download the .deb package from GitHub releases, then install it with:

sudo apt install path/to/your/file

Run ghostab and Ghostab will open.

Download for Linux (Debian)

Linux (Flatpak)

Download the .flatpak package from GitHub releases, then install it with:

flatpak install path/to/your/file

Run flatpak run io.github.aramcz.ghostab and Ghostab will open.
